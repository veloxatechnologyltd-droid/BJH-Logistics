## Verdict

The code is in good shape for a **closed beta with a small, known group**. Access control is thorough and well tested. Four items must be done before inviting testers (B1–B4), and five more should follow soon after (H1–H5).

## What is solid

- All 22 controllers sit behind `SupabaseIdentityGuard` plus a role or scope guard. JWTs are checked for issuer and audience. The service-role key stays in the API.
- Company and service-line scoping is enforced in SQL. Documents download through short-lived signed URLs, issued only after a scope check. Uploads are type-checked by magic bytes and filenames are sanitised.
- Super-admin bootstrap is disabled when `NODE_ENV=production`. Admin-set passwords need at least 12 characters. Suspending a staff member revokes their roles immediately.
- Financial and history records are append-only and enforced by database triggers. Over-payment is blocked by a row lock.
- The seed and production-migration scripts refuse the wrong target host, and production migrations need a typed confirmation.
- The API has Helmet headers, and request logs contain no bodies or query strings.

## Medium and low

- **Customer suspension is not immediate.** It bans the Supabase user but leaves company memberships active. With asymmetric JWT keys, `getClaims` verifies tokens locally, so an access token already issued keeps working until it expires (about 1 h by default). Staff suspension avoids this because it revokes roles.
- **No security headers on the web app** (CSP, `frame-ancestors`). Admin pages can be framed. Add `headers()` in `next.config.ts`.
- 21 other pages still treat a failed access lookup as "no roles", so they show the customer view (open item from 2026-10-08).
- An upload is written to Storage before its database row. If the insert fails, the stored file is orphaned. Uploads are held in memory (up to 25 MB each) on a 512 MB free instance.
- Document library search is an unindexed scan, capped at 200 results with no paging. Fine at beta scale.
- `/documents-preview` (synthetic sample pages) is reachable in production. Whether it stays is undecided (2026-10-08).
- `README.md`'s opening status paragraph is stale ("Jobs, invoices … remain incomplete") and contradicts the README's own system summary.
- Not built and still open in `docs/implementation-checklist.md`: J1–J6 (least-privilege DB role, restore drill, monitoring/MFA, security review, UAT sign-off), G3 multi-container returns, I2 OCR.
